# pyi 自动生成 + pathlib.Path 兼容 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `python -m build` 构建期自动生成并打进 wheel 的 `.pyi` 存根，同时让 pybind 全部路径形参支持 `pathlib.Path`。

**Architecture:** 分两条独立线。(A) 在根 `CMakeLists.txt` 的 `BUILD_PYTHON` 块用 `install(CODE ...)` 在 install 阶段调用 `pybind11-stubgen`，输出写回 staging 的 `modeldeploy/`，scikit-build-core 自动打进 wheel。(B) 在公共头 `csrc/pybind/utils/utils.h` 加 `type_caster<std::filesystem::path>`，再把约 58 个/80 处路径形参从 `std::string` 改为 `std::filesystem::path`（绑定层 `.string()` 转发），C++ 内核不动。

**Tech Stack:** CMake、scikit-build-core、pybind11、pybind11-stubgen；C++17；Windows(pwsh)/Linux。

## Global Constraints

- C++17 编译标准（根 `CMakeLists.txt` 设置），`std::filesystem` 可用。
- 只允许改 `csrc/pybind/**`、`csrc/pybind/utils/utils.h`、根 `CMakeLists.txt`、`pyproject.toml`、`python/__init__.py.in`(如需要)、`docs/`；**禁止改 `csrc/core`、`csrc/runtime`、`csrc/vision`、`csrc/audio` 等内核 API**。
- C++ 内核路径 API 一律保持 `const std::string&`；Path 只在绑定层网关转换 `.string()`。
- pybind 不改内置 `std::string` caster（会与内置冲突），只用自定义 `std::filesystem::path` caster。
- caster 名称用 `os.PathLike[str]`（生成的 pyi 标注为 Path 兼容）。
- stubgen 失败降级为 warning，不得让 wheel 构建失败。
- 若构建环境缺网络/onnxruntime/opencv 无法完整构建，任务内的「全量编译」步骤可降级为「仅对有改动的绑定文件做语法/工具链冒烟」，但最终 Path 冒烟测试必须跑通。
- 每条任务结束前跑冒烟测试 + commit。

```cpp
// pybind11/detail 命名空间内定义 std::filesystem::path 的 type caster，
// 使绑定形参 std::filesystem::path 同时接受 str/bytes/os.PathLike(pathlib.Path)。
// 放在 modeldeploy 命名空间闭合之后。
PYBIND11_NAMESPACE_BEGIN(PYBIND11_NAMESPACE)
PYBIND11_NAMESPACE_BEGIN(detail)
template <>
struct type_caster<std::filesystem::path> {
public:
    PYBIND11_TYPE_CASTER(std::filesystem::path, const_name("os.PathLike[str]"));

    bool load(handle src, bool) {
        // PyOS_FSPath 接受 str/bytes 和任何有 __fspath__ 的对象(pathlib.Path)
        PyObject* fspath = PyOS_FSPath(src.ptr());
        if (!fspath) {
            PyErr_Clear();
            return false;
        }
        // 统一转成 UTF-8 字符串（str 直接；bytes 解码）
        Py_ssize_t size = 0;
        const char* data = nullptr;
        if (PyUnicode_Check(fspath)) {
            data = PyUnicode_AsUTF8AndSize(fspath, &size);
            if (!data) {
                Py_DECREF(fspath);
                PyErr_Clear();
                return false;
            }
        } else if (PyBytes_Check(fspath)) {
            data = PyBytes_AsStringAndSize(fspath, &size);
            if (!data) {
                Py_DECREF(fspath);
                PyErr_Clear();
                return false;
            }
        } else {
            Py_DECREF(fspath);
            return false;
        }
        value = std::filesystem::path(std::string(data, size));
        Py_DECREF(fspath);
        return true;
    }

    static handle cast(const std::filesystem::path& src, return_value_policy, handle) {
        return PyUnicode_FromString(src.string().c_str());
    }
};
PYBIND11_NAMESPACE_END(detail)
PYBIND11_NAMESPACE_END(PYBIND11_NAMESPACE)
```

```cmake
    # 构建期用 pybind11-stubgen 生成 .pyi 存根，写回 staging 的 modeldeploy/，随 wheel 发布。
    # stubgen 失败只告警不阻断构建（PYI_STUBGEN_OK 检查）。
    if (DEFINED Python_EXECUTABLE AND EXISTS "${Python_EXECUTABLE}")
        install(CODE "
            set(_stub_cmd \"${Python_EXECUTABLE}\")
            set(_stub_root \"\${CMAKE_INSTALL_PREFIX}\")
            if(WIN32)
                execute_process(COMMAND cmd /c set \"PYTHONPATH=${_stub_root};%PYTHONPATH%\" \\& \"${_stub_cmd}\" -m pybind11_stubgen modeldeploy --output-dir \"${_stub_root}\"
                    RESULT_VARIABLE _stubgen_rv) 
            else()
                execute_process(COMMAND \"${_stub_cmd}\" -m pybind11_stubgen modeldeploy --output-dir \"${_stub_root}\"
                    WORKING_DIRECTORY \"${_stub_root}\"
                    RESULT_VARIABLE _stubgen_rv)
            endif()
            if(NOT _stubgen_rv EQUAL 0)
                message(WARNING \"pybind11-stubgen failed (rc=\${_stubgen_rv}); wheel will be built without .pyi stubs.\")
            endif()
        ")
    else()
        message(WARNING "Python_EXECUTABLE undefined; skipping pyi stub generation.")
    endif()
```

### Task 4: 改造 `RuntimeOption.set_model_path`

**Files:**

**Interfaces:**
- Consumes: Task 1 caster。
- Produces: `RuntimeOption.set_model_path` 接受 `pathlib.Path`；`RuntimeOption` 首参构造无变化。其它 Runtime 方法（`use_gpu` 等）不受影响。

- [ ] **Step 1: 把成员指针绑定改成 lambda + filesystem::path**

`runtime_pybind.cpp:85-86` 由：

```cpp
.def("set_model_path", &RuntimeOption::set_model_path, pybind11::arg("model_path"),
     pybind11::arg("password") = "")
```

改为：

```cpp
.def("set_model_path",
     [](RuntimeOption& self, const std::filesystem::path& model_path,
        const std::string& password) {

     pybind11::arg("model_path"), pybind11::arg("password") = "")
```

若 `RuntimeOption::set_model_path` 实参只有 `model_path`（无 password），则去掉 `password` 参数与 `.string()` 只传 `self.set_model_path(model_path.string());`。以头文件 `runtime/runtime.h` 中实际签名核对后再定。
